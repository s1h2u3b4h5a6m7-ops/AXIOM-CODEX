# 📈 Portfolio & Watchlist

Companies you track, are diligencing, or hold. Create new entries from **Templates → Company Profile**.

> [!tip] Auto-list (requires the Dataview community plugin)
> ```dataview
> TABLE sector AS "Sector", stage AS "Stage", status AS "Status"
> FROM #company
> WHERE type = "company"
> SORT status ASC, file.name ASC
> ```
